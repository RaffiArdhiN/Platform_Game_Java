# Platform Game Java

Platform Game Java is a 2D platformer developed in Java. In this game, players control a character to jump between platforms, avoid obstacles, and collect points.

## Features

- **2D Graphics**: Provides simple yet engaging visual graphics.
- **Simple Controls**: Players can move the character left, right, and jump.
- **Scoring System**: Records player scores based on in-game achievements.
- **Multiple Levels**: Offers several levels with increasing difficulty.

## System Requirements

- **Java Development Kit (JDK)** version 8 or higher.
- Operating system: Windows, macOS, or Linux.

## Installation and Running the Game

1. **Clone the repository**:
   ```bash
   git clone https://github.com/RaffiArdhiN/Platform_Game_Java.git
2. **Navigate to the project directory**:
   ```bash
   cd Platform_Game_Java
3. **Compile the source code**:
   ```bash
   javac -d bin src/*.java
4. **Run the game**:
   ```bash
   java -cp bin Main

## Project Structure

- `src/`: Contains Java source code.
- `lib/`: Contains external libraries used in the project.
- `bin/`: Output directory for compiled class files.
- `db_score.sql`: SQL script for the player score database.
